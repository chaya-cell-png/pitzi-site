# לחץ כאן ואל תלחץ כאן

אתר גימיקים סטטי בעברית, עם פיצי, הכפתור האדום שנעלב בקלות. HTML, CSS ו-JavaScript נקי, בלי שרת ובלי שלב בנייה.

## הרצה מקומית

```
node scripts/serve.js
```

ואז לפתוח את http://localhost:8080. השרת מגיש את `404.html` לכתובות שלא קיימות, כמו GitHub Pages.

## העלאה ל-GitHub Pages

1. מעלים את התיקייה כמו שהיא למאגר ב-GitHub.
2. ב-Settings ← Pages בוחרים "Deploy from a branch" ואת הענף הראשי.
3. כדי שהתצוגה המקדימה בוואטסאפ תעבוד הכי טוב, יוצרים מחדש את עמודי השיתוף עם הכתובת המלאה של האתר:
   ```
   powershell -ExecutionPolicy Bypass -File scripts\make-og.ps1 -SiteUrl https://USER.github.io/REPO/
   ```

## הוספה או הסרה של גימיק

כל גימיק נרשם כך:

```js
Pitzi.register('my-gimmick', {
  pages: ['home'],   // לא חובה. בלי השדה הזה הגימיק פועל בכל העמודים
  motion: true,      // לא חובה. אם true, מצב רגוע מכבה אותו ומדליק אותו בחזרה
  init() {},         // רץ פעם אחת בטעינה
  enable() {},       // הפעלה
  disable() {}       // כיבוי
});
```

מוסיפים את שם הקובץ לרשימה `GIMMICKS` בראש `js/core.js`. כדי להסיר גימיק מוחקים אותו מהרשימה. גימיק שנכשל נכתב לקונסול ושאר האתר ממשיך לעבוד.

## הערות

- **מונה עולמי (גימיק 21):** נדחה כמו שנקבע באפיון. כרגע מוצג מונה הלחיצות האישי. כשיהיה שירות (למשל Firebase), ממלאים את `COUNTER_URL` ב-`js/gimmicks/global-counter.js`.
- **סאונד:** במקום Howler.js וקבצי שמע, הצלילים נוצרים ב-Web Audio. זה חוסך משקל, וכל צליל נמשך פחות משנייה. הצלילים כבויים כברירת מחדל.
- **ספריות:** canvas-confetti נטענת מ-jsDelivr. Matter.js נטענת מ-cdnjs, ורק כשלוחצים על כפתור הגרביטציה.
- **פרטיות:** שום דבר לא נשלח לשום מקום. ב-localStorage נשמרים רק הביצים שנמצאו, מספרי הלחיצות, והגדרות הצליל והמצב הרגוע.
- **מקלדת:** Esc מפעיל את מצב הבוס. ↑↑↓↓←→←→ הופך את האתר.
- **ביצים ורמזים:** יש 16 ביצים. ב"תפוס את העוגיות" יש שתיים: הביצה המרקדת, וביצה נסתרת על 50 נקודות בסיבוב אחד. נוספו ביצה בסוף תנאי השימוש, ביצה במצב המסיבה הסודי, וביצה לכל משחק: 500 נקודות ב"פיצי רץ", 25 ב"הכה בכפתור הכחול" ו"הביצה המרקדת" שנופלת בזיגזג ב"תפוס את העוגיות". אחרי 3 דקות באתר (הזמן נספר רק כשהלשונית גלויה) פיצי נותן רמז כל שתי דקות וחצי, ולכל ביצה יש רמז עדין ורמז כמעט מפורש. הרמזים כתובים ב-`js/gimmicks/egg-hints.js`.

## המשחק: פיצי רץ!

משחק ריצה בסגנון הדינוזאור של גוגל (`game.html`, הקוד ב-`js/gimmicks/runner.js`, מצויר ב-canvas). בעברית רצים שמאלה, אז העולם מצויר במראה.

- **שליטה:** רווח, חץ למעלה או נגיעה בלוח = קפיצה. חץ למטה = התכופפות. באוויר, חץ למטה מוריד מהר. בטלפון יש כפתורי "קפוץ" ו"התכופף".
- **מכשולים:** כפתור כחול (לפעמים בזוג), גרב בודדת, עוגייה מתגלגלת (מהירה יותר), מחבת, חתול וערימת תנאי שימוש. מ-300 נקודות מופיעים גם יונה עם ביטחון עצמי ופס טעינה מעופף.
- **משפטים:** פתיחה, הצגה של כל מכשול בפעם הראשונה, אבני דרך כל 100 נקודות, "כמעט!" כשעוברים צמוד למכשול, משפט נפילה שונה לכל מכשול, ומשפטים על שיא חדש.
- **לילה:** ב-700 נקודות מחשיך בהדרגה (בלי הבהוב), וב-1400 מאיר שוב.
- המשחק עוצר כשהלשונית מוסתרת, כשחלון פתוח ובמצב בוס. השיא נשמר בדפדפן.

## המשחק: הכה בכפתור הכחול

בסגנון "הכה בחפרפרת" (`whack.html`, הקוד ב-`js/gimmicks/whack.js`). בתפריט, "משחקים" מוביל לשני המשחקים, ובראש כל עמוד משחק יש מעבר ביניהם.

- סיבוב של 30 שניות על לוח של 3×3. כפתור כחול = +1, כפתור זהב = +5, עוגייה = עוד 3 שניות. פיצי = −3, כי אסור ללחוץ עליו.
- הכפתורים מאיצים לאורך הסיבוב, ולקראת הסוף יש שניים בחוץ בבת אחת. את הקצב מכוונים באובייקט `SPEED` בראש `whack.js`. רצף פגיעות בלי פספוס נותן קומבו.
- פיצי מגיב לכל דבר: פגיעה, פספוס, לחיצה על חור ריק, כפתור שברח, לחיצה עליו (משפט שמחריף בכל פעם), חצי סיבוב, חמש שניות אחרונות, ודרגה בסוף הסיבוב.
- במקלדת: המקשים 1 עד 9 לוחצים על החורים. המשחק עוצר כשהלשונית מוסתרת, כשחלון פתוח ובמצב בוס.

## המשחק: תפוס את העוגיות

בסגנון Catch the Ball (`catch.html`, הקוד ב-`js/gimmicks/catch.js`, מצויר ב-canvas). פיצי מחזיק סל וזז ימינה ושמאלה בעזרת העכבר, האצבע או החיצים.

- עוגייה = +1, עוגיית זהב = +5, לב = חיים נוספים (עד שלושה).
- כל שתי עוגיות שנופלות לרצפה מורידות לב (ליד הלבבות מופיע 1/2 אחרי הנפילה הראשונה). כפתור כחול שנתפס בסל מוריד לב מיד.
- כל 17 נקודות מגיע גשם עוגיות קצר (4 שניות). בזמן הגשם אי אפשר לאבד לבבות, רק לצבור נקודות.
- ככל שתופסים יותר, הדברים נופלים מהר יותר.
- פיצי מגיב על כל עשר עוגיות, על רצפים בלי פספוס, על פספוסים, על הלב האחרון ועל שיאים. העיניים שלו עוקבות אחרי מה שנופל.
